Данные и конфиденциальность

Обновлено 29 октября 2026 года

Lull использует аккаунт для сохранения музыкальной библиотеки и продолжения прослушивания на других устройствах. По вопросам работы с данными можно обратиться к владельцу приложения: bin985100@gmail.com.

Вход через Google и Discord

Вход выполняется на стороне выбранного сервиса. Lull не получает пароль Google или Discord. Для аккаунта используются идентификатор пользователя, адрес электронной почты и доступные имя и изображение профиля. Авторизацию и облачную базу обслуживает Supabase.

Подключение YouTube

При входе через Google Lull запрашивает разрешение только на чтение данных YouTube. После согласия приложение автоматически переносит доступные музыкальные видео из отметок «Нравится» и пользовательских плейлистов через YouTube Data API. Lull не изменяет и не удаляет плейлисты и отметки в YouTube. Часть подборок YouTube Music недоступна через этот API.

Доступ Google используется для этого импорта. Данные Google не продаются, не используются для рекламы и не передаются для обучения моделей общего назначения. Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Что сохраняется

В облачной библиотеке Lull сохраняются любимые композиции, плейлисты и их состав, сохранённые подборки, история и статистика прослушивания, очередь, настройки и позиция воспроизведения. Эти данные связываются с аккаунтом Lull и синхронизируются между устройствами. Поисковые запросы, параметры вывода звука и данные подключения к собственному серверу остаются на устройстве.

Приложение хранит сессию входа, чтобы не запрашивать вход при каждом запуске. На Android используется системное защищённое хранилище, в настольном приложении — доступное системное шифрование; в браузере сессия хранится в данных сайта. Для автоматического продления разрешённого доступа YouTube его ключи хранятся отдельно в зашифрованном Supabase Vault и используются только серверным обработчиком Lull. Другие пользователи и общие таблицы библиотеки не получают эти ключи. Передача запросов авторизации и библиотеки использует HTTPS. Доступ к облачной библиотеке ограничен владельцем аккаунта правилами базы данных.

Сервисы и сетевые запросы

Для работы используются Supabase, Google/YouTube, Discord и сервер Lull. При соединении соответствующий сервис получает необходимые технические сведения, например IP-адрес и параметры запроса. Правила этих сервисов: Supabase, Google, Discord. Работа с YouTube также регулируется условиями YouTube.

Как отозвать доступ и запросить удаление

Доступ Google можно отозвать в настройках разрешений Google, доступ Discord — в разделе «Авторизованные приложения» Discord. Выход из Lull на устройстве завершает локальную сессию; он сам по себе не удаляет облачную библиотеку.

Для удаления аккаунта Lull и связанных облачных данных отправь запрос на bin985100@gmail.com с адреса аккаунта. Не отправляй пароль или токены доступа. Удаление данных Lull не удаляет данные из Google, YouTube или Discord; ими нужно управлять в соответствующем сервисе.
